This flasher needs the Web Serial API

Flashing happens directly from the browser over USB, which requires Google Chrome or Microsoft Edge on a desktop computer, served over HTTPS. Safari, Firefox and mobile browsers are not supported.

EN · Install on Android

                  
    
                    
  1. Tap Download the app and wait for the .apk to finish downloading.
    2. 
                    
  2. Open the downloaded file. Android will say the source isn't allowed — tap Settings.
    3. 
                    
  3. Turn on Allow from this source (Settings → Apps → Special app access → Install unknown apps), then go back and install.
    4. 
                    
  4. If Play Protect warns the app is unsafe, choose More details → Install anyway — the app is just unsigned, not malicious.
    5. 
                    
  5. Open the app and grant Bluetooth and Location permissions so it can reach the board.
    6. 
                  

                

                

                  
ID · Pasang di Android

                  
    
                    
  1. Ketuk Download the app dan tunggu berkas .apk selesai diunduh.
    2. 
                    
  2. Buka berkas hasil unduhan. Android akan bilang sumbernya tidak diizinkan — ketuk Setelan.
    3. 
                    
  3. Aktifkan Izinkan dari sumber ini (Setelan → Aplikasi → Akses aplikasi khusus → Instal aplikasi tak dikenal), lalu kembali dan pasang.
    4. 
                    
  4. Jika Play Protect memperingatkan aplikasi tidak aman, pilih Detail selengkapnya → Tetap instal — aplikasi ini hanya tak bertanda tangan, bukan berbahaya.
    5. 
                    
  5. Buka aplikasi dan beri izin Bluetooth serta Lokasi agar bisa terhubung ke board.
